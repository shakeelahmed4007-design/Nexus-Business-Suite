# Nexus — Business Management Suite

Enterprise multi-tenant ERP, POS, CRM, Stock Inventory, Invoicing & Team Access Management System.

## Features
- **Multi-Tenant Architecture**: Dynamic shop management with Super Admin and Shop Admin roles.
- **Granular Access Control**: Module and action level CRUD (View, Create, Edit, Delete) permissions.
- **Sales & Invoicing**: Real-time invoice creation synced with Supabase Database.
- **CRM & Inventory**: Lead management, stock tracking, warehouse and supplier management.
- **Modern UI**: Dark/Light mode support with Framer Motion animations and responsive layouts.

## Tech Stack
- React 18 + TypeScript + Vite
- TailwindCSS + Framer Motion + Lucide Icons
- Supabase (Auth, RLS Policies, PostgreSQL Database)
